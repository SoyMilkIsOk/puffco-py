Engineered for Performance

Modern Architecture, Zero Hassle

Everything you need to integrate Puffco devices into Python apps, desktop dashboards, and Home Assistant.

⚡

Lorax VFS Protocol

Native support for Puffco firmware using Lorax Virtual File System sequence multiplexing and SHA-256 challenge-response authentication.

⏱️

Sub-100ms Streaming

Adaptive polling engine streams ~16 FPS (60ms) during active heating and throttles to power-saving mode (250ms) when idle.

🧵

Thread-Safe GUI Ready

Includes ThreadedPuffcoClient to power synchronous UI toolkits (Tkinter, PyQt, PySide) without blocking dispatch threads.

🍏

macOS Status Bar Widget

Comes with a ready-to-run native menu bar app powered by rumps, showing live temps and one-click session triggers.

🔍

Auto-Discovery Engine

Scans BLE advertisements and filters nearest devices by manufacturer OUI and Lorax GATT UUIDs automatically.

📊

Hardware Telemetry Model

Clean dataclass models for 3D/3DXL chamber detection, battery %, charging state, lifetime dabs odometer, and saved profiles.

Under The Hood

Lorax VFS Handshake Flow

How puffco-ble handles authentication and bidirectional telemetry over Bluetooth Low Energy.

STEP 01

GATT Connection

Bleak discovers device with Lorax service UUID and establishes an MTU-negotiated link.

e276967f-ea8a-478a...
STEP 02

Seed Challenge

Client sends Opcode 0x00 to request a 16-byte cryptographically secure random access seed.

GET_ACCESS_SEED (0x00)
STEP 03

SHA-256 Auth Token

Client calculates SHA256(MasterKey + Seed)[:16] and transmits Opcode 0x01 to unlock the VFS.

UNLOCK_ACCESS (0x01)
STEP 04

Stream Telemetry

Client polls Lorax VFS paths for live bowl temperature, state ID, and battery level.

/p/app/htr/temp
