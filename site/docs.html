puffco-ble Documentation

Complete developer documentation and reverse-engineering reference for Puffco Peak Pro and Proxy Bluetooth Low Energy hardware.

Python 3.9–3.12 Bleak GATT Lorax VFS v5.x MIT License

1. Introduction

puffco-ble is a standalone, lightweight, asynchronous Python library designed to communicate with Puffco Peak Pro (V1, V2, Limited Editions) and Puffco Proxy vaporizers using standard Bluetooth Low Energy (BLE).

Modern Puffco devices use a proprietary firmware protocol known as the Lorax Virtual File System (VFS). Rather than using fixed GATT characteristics for every sensor, Puffco multiplexes virtual file paths over a single write characteristic and a notification characteristic. puffco-ble implements this protocol natively, providing:

  • Low latency streaming: Adaptive polling engine operating at up to ~16 FPS (60ms) during active heating sessions.
  • Cryptographic authentication: Automatically solves the SHA-256 access seed challenge required by modern firmware.
  • Desktop GUI friendly: Dedicated background-worker thread client (ThreadedPuffcoClient) for Tkinter, PyQt, and macOS status bar widgets.
  • Hardware telemetry: Live bowl temperature (°F/°C), battery %, charging status, chamber detection (3D, 3DXL, Proxy), and lifetime dab counter.

2. Installation

puffco-ble can be installed via PyPI or built directly from source. Requires Python 3.9 or higher.

Standard Installation (PyPI)

bash 
pip install puffco-ble

Installing Optional Extras

To include optional Rich CLI formatting and macOS menu bar widget dependencies:

bash 
# Install with CLI and macOS GUI support
pip install "puffco-ble[cli,gui]"

Installing from GitHub Repository

bash 
git clone https://github.com/SoyMilkIsOk/puffco-ble.git
cd puffco-ble
pip install -e .

4. Async Python Quickstart (Core Client)

PuffcoClient is an asynchronous context manager powered by asyncio and bleak. It automatically discovers the nearest Puffco device, authenticates, and starts a telemetry polling engine.

python 
import asyncio
from puffco_ble import PuffcoClient

async def main():
    # Automatically scans for and connects to nearest Puffco
    async with PuffcoClient() as client:
        print(f"Connected to: {client.telemetry.device_name}")
        print(f"Chamber: {client.telemetry.chamber_name} | Battery: {client.telemetry.battery_pct}%")

        # Register a live stream update listener
        def on_telemetry(t):
            print(f"\rTemp: {t.live_temp_f:.1f}°F | State: {t.state_name}", end="")

        client.add_telemetry_listener(on_telemetry)
        await client.start_telemetry_stream()

        # Stream for 15 seconds
        await asyncio.sleep(15)

asyncio.run(main())

5. Synchronous & Desktop GUI Quickstart

If you are building a desktop GUI (Tkinter, PyQt, PySide, wxPython) or a synchronous automation script, use ThreadedPuffcoClient. It runs the asynchronous BLE event loop on an isolated daemon worker thread and exposes simple, non-blocking synchronous methods to your main UI thread:

python 
import time
from puffco_ble import ThreadedPuffcoClient

client = ThreadedPuffcoClient()

# Register real-time callbacks from background worker thread
client.add_telemetry_listener(lambda t: print(f"Live Temp: {t.live_temp_f:.1f}°F"))

client.start()

if client.wait_connected(timeout=10.0):
    print(client.telemetry.summary())
    
    # Thread-safe session controls
    client.set_profile(slot=1)
    client.start_session()
    time.sleep(10)
    client.boost()
    time.sleep(10)
    client.stop_session()

client.stop()

6. Command-Line Interface (CLI) Manual

The package includes an out-of-the-box CLI utility named puffco-ble for rapid terminal interaction:

Command Options Description
puffco-ble scan -t, --timeout <sec> (default: 5.0) Scans BLE advertisements and prints discovered Puffco devices with MAC and RSSI signal.
puffco-ble monitor --mac <MAC/UUID> (optional) Live streams an interactive terminal HUD with bowl temp, battery %, and sesh state.
puffco-ble info --mac <MAC/UUID> (optional) Dumps hardware serial, firmware version, lifetime dabs odometer, and all 4 profiles.
puffco-ble sesh <action> start, stop, or boost
--mac <MAC/UUID>		 Sends immediate heating commands to the connected hardware.
💡
Targeting Specific Units: If multiple devices are in range, supply --mac AA:BB:CC:DD:EE:FF (or macOS CoreBluetooth UUID) to target a specific vaporizer.

7. Native macOS Menu Bar Widget

puffco-ble includes a native macOS status bar menu app built using rumps in examples/04_mac_menu_widget.py:

bash 
# Install rumps GUI dependency
pip install "puffco-ble[gui]"

# Launch the widget
python3 examples/04_mac_menu_widget.py

The widget displays live bowl temperature directly in your menu bar (🔥 520°F (35s) or 💨 480°F | 85% when idle) and provides one-click dropdown actions to start, boost, or abort sessions.

8. Python API Reference

PuffcoClient Methods

Method Return Description
async connect(timeout=10.0) bool Connects via Bleak GATT and solves the Lorax SHA-256 access seed challenge.
async disconnect() None Gracefully terminates GATT connection and stops polling loops.
async start_session() None Triggers heating session using the currently active profile.
async stop_session() None Aborts active heating session immediately.
async boost() None Applies heat boost (+15s duration and +10°F target temp).
async set_profile(slot: int) None Switches active profile slot (integer 0 to 3).
async set_stealth_mode(enabled: bool) None Toggles device mood lights on or off.
add_telemetry_listener(callback) None Registers a function callback(telemetry) called on state changes.

9. Telemetry Model (PuffcoTelemetry)

The telemetry dataclass is accessible via client.telemetry:

Property Type Description
live_temp_f float Current real-time bowl temperature in degrees Fahrenheit.
target_temp_f float Target setpoint temperature of the active profile.
battery_pct int Battery state of charge percentage (0–100%).
is_charging bool True if device is plugged into USB-C or resting on Qi dock.
chamber_name str Detected chamber type ("3D", "3DXL", "Proxy", "None").
operating_state OperatingState Enum: IDLE, HEAT_PREHEAT, HEAT_ACTIVE, HEAT_FADE.
lifetime_dabs int Total completed sessions odometer stored in hardware memory.

10. Reverse-Engineered Lorax VFS Protocol

Puffco firmware implements a sequence-multiplexed file system over standard Bluetooth LE:

GATT Entity UUID Properties
Service e276967f-ea8a-478a-a92e-d78f5dd15dd5 Primary Lorax BLE Service
Command Characteristic 60133d5c-5727-4f2c-9697-d842c5292a3c Write Without Response
Reply Characteristic 8dc5ec05-8f7d-45ad-99db-3fbde65dbd9c Notify / Indicate

Lorax VFS Paths Reference

  • /p/app/stat/id: Operating state byte (0 = Idle, 1 = Preheat, 2 = Sesh, 3 = Fade).
  • /p/app/htr/temp: Chamber temperature sensor reading.
  • /p/app/mc: Mode control opcode (0x07 = Start, 0x08 = Stop, 0x09 = Boost).
  • /p/bat/soc: Battery State of Charge percentage.
  • /p/app/odom/0/nc: Lifetime completed dabs counter.

11. Troubleshooting & FAQs

Device not discovered during scan

Ensure your Puffco is powered on and within 5–10 feet. If your device is currently connected to the official Puffco Connect smartphone app, Bluetooth Low Energy will reject secondary central connections. Disconnect the official app and re-run puffco-ble scan.

Permission denied on macOS

In macOS Ventura and Sonoma, terminal emulators require explicit Bluetooth authorization. Go to System Settings > Privacy & Security > Bluetooth and ensure your terminal app (Terminal, iTerm2, Alacritty, or VS Code) is toggled ON.
